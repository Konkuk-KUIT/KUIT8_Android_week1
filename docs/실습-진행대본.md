# 1주차 실습 진행 대본 — 멤버 소개 화면

약 35분. 설명과 따라 입력하는 시간 20분, 학생이 시안을 보고 직접 완성하고 값을 바꾸는 시간 15분으로 진행한다. 대괄호 안은 강사용 지시이며 읽지 않는다.

[피그마 실습 시안](https://www.figma.com/design/qS78p5XqLhETQ4pXV8kAj5?node-id=411-6)을 한쪽에 열어 둔다. 이 대본은 강사용이며 피그마에는 넣지 않는다. 완성 코드는 `app/src/main/java/com/example/myapplication/PracticeScreen.kt`에서 확인할 수 있다.

## 1. 화면 뼈대 — 00:00~04:00

[완성 시안의 제목, 프로필 카드, 소개 문구, 관심 분야, 응원하기 버튼을 위에서 아래로 가리킨다.]

네. 이제 앞에서 배운 내용으로 이 멤버 소개 화면을 만들어 보겠습니다. 위에는 제목과 프로필 카드가 있고, 그 아래에는 소개 문구, 관심 분야, 버튼이 있습니다.

전체적으로는 세로로 배치되어 있죠. 그래서 바깥은 Column으로 만들겠습니다. 관심 분야는 가로로 나란히 놓여 있으니까 Row를 사용하면 되겠죠.

[앱 패키지에 `PracticeScreen.kt`를 만든다. 아래는 첫 단계용 코드다. 완성 코드 옆에 중복해서 붙여 넣는 것이 아니라, 이 코드부터 작성하고 단계마다 바꾼다.]

```kotlin
@Composable
fun MyProfileScreen(modifier: Modifier = Modifier) {
    Column(
        modifier = modifier
            .padding(horizontal = 24.dp)
            .padding(top = 32.dp, bottom = 24.dp),
        verticalArrangement = Arrangement.spacedBy(24.dp),
    ) {
        Text("멤버 소개")
    }
}

@Preview(showBackground = true, widthDp = 360, heightDp = 480)
@Composable
private fun MyProfilePreview() {
    MyProfileScreen(modifier = Modifier.fillMaxSize())
}
```

MyProfileScreen은 우리가 직접 만드는 화면 함수입니다. 바깥에서 받은 modifier를 Column에 전달했고요. 양옆에는 24dp, 위에는 32dp, 아래에는 24dp 여백을 주었습니다.

자식 사이의 간격은 verticalArrangement에 Arrangement.spacedBy(24.dp)를 넣어서 한 번에 정하겠습니다. Column 안에 컴포저블을 더 넣으면 세로로 24dp씩 떨어져 배치됩니다.

[추가 import는 `androidx.compose.foundation.layout.Arrangement`이다.]

밑에는 이 화면을 확인할 프리뷰입니다. 360과 480은 확인할 프리뷰의 크기예요. 실제 화면 함수의 너비를 360dp로 고정한 것은 아닙니다.

[`MainActivity.kt`를 열어 클래스와 `setContent`를 함께 보여 준다. 앱 실행에 필요한 준비 코드는 유지하고, `setContent`에서 `MyProfileScreen`을 호출하는 위치만 짚는다.]

```kotlin
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            MyProfileScreen(
                modifier = Modifier.fillMaxSize().background(profileBackground),
            )
        }
    }
}
```

앱에서 확인할 때도 MainActivity 안에 있는 setContent에서 이 함수를 호출하면 됩니다. 여기까지 준비되어 있으니까, 우리는 MyProfileScreen 안을 채워 나가겠습니다.

[약 2분간 입력과 프리뷰 확인. 글자가 보이면 다음으로 넘어간다.]

## 2. 공통 색상·글꼴·글자 스타일 — 04:00~09:00

[피그마 옆에 정리된 색상·글자 스타일 목록을 보여 준다. 파일명 찾기로 `Color.kt`를 연다.]

먼저 화면에서 사용할 색상과 글자 스타일을 가져오겠습니다. 피그마에 목록이 있으니까 여기의 값을 보고 변수로 선언하면 됩니다.

Color.kt에는 아래 다섯 색상을 넣겠습니다.

```kotlin
val profileBackground = Color(0xFFF4F7FC)
val profileText = Color(0xFF17243B)
val profileMuted = Color(0xFF58667C)
val profileBorder = Color(0xFFD9E2EF)
val profileWhite = Color.White
```

배경, 진한 글자, 보조 설명, 테두리, 흰색입니다. 필요한 곳에서 이 변수를 가져다 쓰겠습니다.

[파일명 찾기로 `Type.kt`를 연다. 먼저 `res/font`에 준비된 `noto_sans_kr_regular.otf`, `noto_sans_kr_bold.otf` 두 파일을 보여 준다. 학생 프로젝트에는 이 두 파일을 같은 폴더에 복사한다.]

글꼴은 Noto Sans KR 하나를 사용하겠습니다. Regular는 보통 굵기, Bold는 굵은 글자예요. 서로 다른 글꼴 두 개가 아니라 같은 글꼴의 굵기가 다른 파일입니다.

먼저 이 두 파일로 FontFamily를 하나 선언하겠습니다. 각 파일이 어느 굵기에 해당하는지 함께 적어 주면 됩니다.

```kotlin
val profileFontFamily = FontFamily(
    Font(R.font.noto_sans_kr_regular, FontWeight.Normal),
    Font(R.font.noto_sans_kr_bold, FontWeight.Bold),
)
```

[추가 import는 `androidx.compose.ui.text.font.Font`, `androidx.compose.ui.text.font.FontFamily`, `com.example.myapplication.R`이다. `Font`는 Compose가 제공하는 API이고, `profileFontFamily`는 우리가 선언한 변수다.]

글꼴은 font 폴더에 넣습니다. R.font 뒤에는 확장자를 뺀 파일 이름을 적습니다.

[같은 `Type.kt`에 아래 네 스타일 변수를 추가한다. 반복되는 선언은 준비된 코드에서 붙여 넣어도 된다.]

```kotlin
val profileTitleStyle = TextStyle(
    fontFamily = profileFontFamily,
    fontSize = 28.sp,
    lineHeight = 40.sp,
    fontWeight = FontWeight.Bold,
)
val profileNameStyle = TextStyle(
    fontFamily = profileFontFamily,
    fontSize = 24.sp,
    lineHeight = 34.sp,
    fontWeight = FontWeight.Bold,
)
val profileBodyStyle = TextStyle(
    fontFamily = profileFontFamily,
    fontSize = 14.sp,
    lineHeight = 24.sp,
    fontWeight = FontWeight.Normal,
)
val profileActionStyle = TextStyle(
    fontFamily = profileFontFamily,
    fontSize = 14.sp,
    lineHeight = 22.sp,
    fontWeight = FontWeight.Bold,
)
```

제목, 이름, 본문, 버튼 글자에 사용할 스타일입니다. 이 변수들을 Text의 style 파라미터에 전달하면 됩니다. 네 스타일의 fontFamily에는 모두 같은 profileFontFamily를 넣었습니다. fontFamily가 글꼴을 정하고, fontWeight가 그 글꼴의 굵기를 선택합니다.

[`PracticeScreen.kt`로 돌아와 바깥 Column의 modifier를 다음과 같이 바꾼다.]

```kotlin
modifier = modifier
    .background(profileBackground)
    .padding(horizontal = 24.dp)
    .padding(top = 32.dp, bottom = 24.dp)
```

전체 배경을 먼저 칠하고 그 안에 여백을 주었습니다. 그래서 빈 공간에도 배경색이 보이게 됩니다.

이번 실습에서는 피그마의 배치 수치를 dp로, 글자 크기를 sp로 옮기겠습니다. 피그마의 숫자가 기기의 실제 픽셀 수와 같다는 뜻은 아닙니다.

[약 2분간 입력과 import 확인. 연한 배경이 적용되었는지 확인한다.]

## 4. 소개와 관심 분야 — map과 forEach — 12:00~17:00

[`PracticeScreen.kt`에 `MyIntroduction`을 추가한다.]

```kotlin
@Composable
private fun MyIntroduction() {
    Text(
        text = "작은 아이디어를 앱으로 만들고 싶어요.\n함께 배우며 한 걸음씩 성장하겠습니다.",
        color = profileMuted,
        style = profileBodyStyle,
    )
}
```

그다음에는 카드 아래에 소개 문구를 넣겠습니다. 여기서는 Text 하나면 됩니다. 문자열 안의 역슬래시 n은 줄을 바꾸는 표시예요.

색상은 보조 설명에 쓰는 profileMuted, 스타일은 profileBodyStyle을 사용했습니다.

[같은 파일에 `MyInterests`를 추가한다.]

```kotlin
@Composable
private fun MyInterests() {
    val interests = listOf("Kotlin", "Compose", "Android")
    val labels = interests.map { "#" + it }

    Row(horizontalArrangement = Arrangement.spacedBy(8.dp)) {
        labels.forEach { label ->
            Text(
                text = label,
                modifier = Modifier
                    .border(1.dp, profileBorder)
                    .background(profileWhite)
                    .padding(horizontal = 8.dp, vertical = 4.dp),
                color = profileMuted,
                style = profileBodyStyle,
            )
        }
    }
}
```

관심 분야는 앞에서 배운 리스트와 map, forEach로 만들어 보겠습니다. 먼저 관심 분야 세 개를 리스트에 넣었습니다.

[interests와 labels를 차례로 가리킨다.]

표시할 때는 앞에 샵을 붙이고 싶어요. 문자열 두 개를 +로 이어 붙여서 map으로 각 문자열 앞에 샵을 붙인 새로운 리스트를 만들었습니다. 원래 interests의 값은 그대로 있고, labels에는 샵 Kotlin, 샵 Compose, 샵 Android가 들어갑니다.

여기의 it은 지금 변환하고 있는 문자열 하나입니다. 파라미터가 하나라서 이름과 화살표를 생략하고 it으로 쓴 형태예요.

그다음에는 이 labels를 forEach로 하나씩 꺼내서 Text에 전달했습니다. label에는 첫 번째 문자열, 두 번째 문자열, 세 번째 문자열이 차례로 들어가겠죠. 그래서 Text를 세 번 복사해서 적지 않아도 관심 분야 세 개가 표시됩니다.

map은 표시할 문자열의 목록을 새로 만들고, forEach는 그 목록의 각 항목으로 Text를 만드는 데 사용한 겁니다.

Row에서는 horizontalArrangement에 Arrangement.spacedBy(8.dp)를 넣었습니다. 그러면 관심 분야 사이에 가로로 8dp씩 간격이 생깁니다. 각 Text의 padding은 테두리 안쪽 여백이고, spacedBy는 서로 다른 Text 사이의 간격입니다.

[바깥 `MyProfileScreen`의 카드 아래에 추가한다.]

```kotlin
MyIntroduction()
MyInterests()
```

[약 2분간 직접 입력. 카드 아래 소개 두 줄과 샵이 붙은 관심 분야 세 개가 보이는지 확인한다.]

이제 아래쪽에 응원하기 버튼을 넣겠습니다.

## 5. 실제 Button과 남은 세로 공간 — 17:00~20:00

[`PracticeScreen.kt`에 `MyCheerButton`을 추가한다.]

```kotlin
@Composable
private fun MyCheerButton() {
    Button(
        onClick = {},
        modifier = Modifier.fillMaxWidth().height(48.dp),
    ) {
        Text(text = "응원하기", style = profileActionStyle)
    }
}
```

여기서는 Compose에서 제공하는 Button을 사용하겠습니다. 가로는 부모가 허용하는 공간을 채우고, 높이는 48dp입니다.

onClick은 버튼을 눌렀을 때 실행할 함수를 받는 자리입니다. 지금은 중괄호 안을 비워 두겠습니다. 버튼을 만들고 눌러 볼 수 있지만, 눌렀을 때 실행할 동작은 아직 없는 상태입니다.

버튼의 색상은 기본값을 사용하겠습니다. 마지막 람다 안에는 버튼에 표시할 Text를 넣었습니다.

[필요한 import는 `androidx.compose.material3.Button`이다. 바깥 `MyProfileScreen`을 아래 완성 형태로 맞춘다.]

```kotlin
@Composable
fun MyProfileScreen(modifier: Modifier = Modifier) {
    Column(
        modifier = modifier
            .background(profileBackground)
            .padding(horizontal = 24.dp)
            .padding(top = 32.dp, bottom = 24.dp),
        verticalArrangement = Arrangement.spacedBy(24.dp),
    ) {
        MyProfileHeader()
        MyProfileCard()
        MyIntroduction()
        MyInterests()
        Spacer(Modifier.weight(1f))
        MyCheerButton()
    }
}
```

버튼을 바로 호출하면 관심 분야 아래에 정해 둔 간격만큼 떨어져 놓이겠죠. 시안에서는 아래쪽에 있으니까, 그 사이에 남은 공간을 차지할 Spacer를 넣겠습니다.

[Spacer의 `weight(1f)`를 가리킨다.]

weight는 Modifier에서 제공하는 기능입니다. 지금은 Column 안이니까 세로 방향으로 남은 공간을 나눕니다. 다른 내용이 차지하고 남은 높이를 이 Spacer가 전부 가져가는 것이죠. 그래서 버튼이 아래쪽에 놓이게 됩니다.

자식 사이의 24dp 간격은 Column의 spacedBy가 먼저 확보합니다. 그 간격과 다른 내용이 차지하고 남은 높이를 weight가 적용된 Spacer 하나가 채우는 것입니다.

[약 1분간 입력과 실행 확인. 버튼이 아래에 있고 글자가 가운데에 보이는지 확인한다.]

네. 이제 제목, 프로필 카드, 소개 문구, 관심 분야, 버튼까지 들어갔습니다. 여기까지는 같이 작성했고요. 남은 시간에는 직접 마저 완성하고 값을 바꿔 보겠습니다.

## 6. 학생이 시안을 보고 마저 완성하기 — 20:00~35:00

[대본과 완성 코드를 내려 두고 피그마 시안을 보여 준다. 학생들이 자기 코드에서 수치를 확인하도록 한다.]

지금부터 15분 동안 피그마를 보면서 본인 화면을 완성해 주세요. 요소를 클릭하면 크기가 나오고, 하나를 선택한 뒤 Option이나 Alt를 누른 채 다른 요소에 마우스를 올리면 간격을 볼 수 있습니다.

먼저 아직 입력하지 못한 부분을 마저 작성해 주세요. 카드 안쪽 여백, 카드와 소개 사이의 간격, 버튼의 높이와 아래 여백은 시안에서 직접 확인해 보시면 됩니다.

그다음에는 interests의 세 항목 중 하나를 짧은 다른 관심 분야로 바꿔 보세요. Text를 수정하지 않고 리스트의 값만 바꿔도 화면이 바뀌는지 확인하시면 됩니다.

Color.kt의 profileMuted를 다른 색상으로 바꿔 보세요. 그 변수를 함께 사용하는 소개 문구와 관심 분야의 글자 색이 바뀌는지 확인한 뒤, 시안의 색상으로 돌려놓겠습니다.

색상과 글자 스타일은 시안 옆 목록을 보고 확인해 주세요. 스타일 값이 다르면 Type.kt의 공통 변수를 수정하면 됩니다. 이름과 소개 문구는 본인이 원하는 내용으로 바꾸셔도 됩니다.
